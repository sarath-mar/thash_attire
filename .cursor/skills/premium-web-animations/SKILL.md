# Premium Web Animations

## Animation Direction
Create an elegant, premium fashion-editorial experience.

Use:
- GSAP for advanced timelines and scroll-triggered effects.
- Motion for lightweight interface animations where appropriate.
- Vue transitions for page and component transitions.
- CSS animations for simple effects.

Only use libraries already installed or obtain approval before installing new dependencies.

## Animation Techniques
- Smooth hero image reveals.
- Staggered text animations.
- Scroll-triggered product reveals.
- Image clipping and reveal effects.
- Subtle parallax photography.
- Elegant page transitions.
- Product image hover transitions.
- Smooth navigation interactions.
- Animated collection banners.

## Animation Rules
- Animations should feel premium, not distracting.
- Avoid excessive bouncing and spinning.
- Avoid unnecessary loading animations.
- Use transform and opacity where possible.
- Prevent layout shifts.
- Respect prefers-reduced-motion.
- Optimize for mobile devices.
- Clean up GSAP timelines and ScrollTriggers when Vue components unmount.

## Performance
- Lazy-load images.
- Avoid animating expensive CSS properties.
- Keep scroll interactions smooth.
- Avoid unnecessary animation dependencies.
- Maintain good Core Web Vitals.
