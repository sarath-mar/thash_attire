# Thash Attire Brand UI

## Brand Identity
- Brand: Thash Attire
- Business: Women's casual wear, kurta-style dresses and co-ord sets.
- Target audience: Indian women, especially Kerala customers.
- Positioning: Premium, elegant, affordable everyday fashion.
- Visual personality: Minimal, sophisticated, feminine and modern.

## Design Direction
- Use premium Indian fashion e-commerce websites as inspiration.
- Prefer clean, editorial layouts over generic e-commerce templates.
- Use light backgrounds, warm neutrals and subtle dark pink accents.
- Use elegant typography with strong visual hierarchy.
- Give product photography maximum importance.
- Avoid excessive rounded cards, gradients and unnecessary shadows.
- Avoid cluttered layouts and generic Bootstrap designs.

## Brand Colors
Create reusable SCSS variables.
- Primary: Dark pink / muted rose.
- Background: Warm white / ivory.
- Text: Deep charcoal.
- Secondary: Muted beige.
- Accent: Soft blush.

Do not introduce unrelated colors without a design reason.

## UI Principles
1. Every page must look like part of the same brand.
2. Use whitespace intentionally.
3. Prioritize product images and product discovery.
4. Use consistent spacing and typography.
5. Make mobile shopping experience excellent.
6. Keep interfaces simple and conversion-focused.
7. Avoid unnecessary UI elements.

## Technical Requirements
- Vue 3.
- Vuetify 3.
- Use reusable Vue components.
- Use SCSS variables in a separate styles folder.
- Use Vuetify validation where applicable.
- No Tailwind CSS.
- No Pinia.
- No TypeScript.
- Keep components readable and maintainable.

## Important
Before implementing a new page:
1. Inspect the existing project structure.
2. Understand existing components and styles.
3. Reuse existing components wherever possible.
4. Do not unnecessarily modify working functionality.
5. Maintain the existing API integration and business logic.
